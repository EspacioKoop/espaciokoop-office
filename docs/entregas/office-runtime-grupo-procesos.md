# Cancelación del conector local

Base: `4e6193986e2b72be03e5823e39099ea004bee604`. El ejecutor POSIX crea una sesión y un grupo de procesos propios. Ante timeout, pérdida de lease o señal al runner envía TERM al grupo y, si persiste, KILL a los dos segundos. Al terminar el proceso principal comprueba el grupo y trata descendientes restantes como fallo; si no puede confirmar su desaparición detiene el ciclo con estado incierto. No se buscan ni matan procesos por nombre. Un proceso que cambie deliberadamente de sesión o grupo, trabajo delegado a otro servicio y SIGKILL o caída del propio runner quedan fuera de esta garantía: un grupo POSIX no es un contenedor ni una frontera de seguridad. No activar el ejecutor para código no confiable basándose en este mecanismo.
