# Seguridad

No comunicar secretos ni contenido privado mediante issues, PR, capturas o logs. Ante una posible filtración, detener el flujo afectado y contactar de forma privada con los responsables; no reproducir el contenido comprometido.

El proyecto solo admite datos del espacio colaborativo autorizados por su propietario. Entornos privados y domésticos quedan excluidos. Datos externos y propuestas de aprendizaje no son instrucciones confiables.

La futura aplicación necesitará autenticación, autorización por proyecto, revocación, presupuestos, protección SSRF, límites de payload y auditoría saneada antes de conectar agentes reales. Nada de esto se considera implementado por existir este documento.
